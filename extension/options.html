Bambuddy Model Importer

Browser extension settings

Importer connection

Enter the base URL of the Bambuddy Model Importer service, not the Bambuddy URL. Do not add a trailing slash.

The password is exchanged for a signed session token. The extension stores the token locally in this browser profile; it does not store your password or Bambuddy API key.

Privacy and permissions

  • The extension reads the active tab URL only after you click its toolbar button.
  • It sends that URL and your selected file IDs to your own importer service.
  • Model downloads happen server-side in the importer. The extension does not download model files or contact the model sites directly.
  • The extension asks for permission to contact only the importer hostname you configure.
  • Your Bambuddy API key remains on the importer server and is never entered into this extension.

How to connect

  1. Deploy the Bambuddy Model Importer and set its IMPORTER_PASSWORD.
  2. Enter the importer's URL and that password above.
  3. Allow the browser permission for that importer host.
  4. Open a supported model page and click the extension icon.

The extension uses the importer's versioned API. Importer-only updates can add model sources without requiring a new extension build, as long as API v1 remains compatible.
